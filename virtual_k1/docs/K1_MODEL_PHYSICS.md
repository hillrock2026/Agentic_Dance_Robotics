## 3. 检查结论

1. **质量**: 无零质量/负质量异常; 所有含关节 body 质量均 > 0;
   左右对称关节段质量一致 (相对误差 < 0.1%)。
2. **惯性**: 25 个有质量 body 的惯性矩阵 (由 diaginertia + iquat
   重建) 全部正定, 且满足刚体三角不等式 I1+I2≥I3。
3. **碰撞**: 覆盖躯干/头/前臂/髋/膝/足; 足底为独立碰撞盒,
   与视觉 mesh 分离 —— 属常见简化建模, 未见异常重叠或缺失。
4. **限制 (记录, 非错误)**: 大腿 (hip_yaw→knee 段) 无碰撞体,
   上臂 (肩→肘) 无碰撞体; 若后续舞蹈动作涉及大腿/上臂接触地面
   或身体互碰, 需评估是否补充碰撞几何 (属后续阶段决策)。
5. 传感器: imu site 上有 framequat (姿态) 与 gyro (角速度) 两个
   官方传感器, 带噪声参数, 可用于模拟真实 IMU 读数。
